# EDINET_COVERAGE

## Coverage分類

EDINET実装前に各候補を以下へ分類する。

- A: J-Quantsで十分取得可能。原則EDINET本番再実装不要。
- B: J-QuantsにもあるがEDINETに追加価値がある。両sourceを保持。
- C: J-Quantsにない、または著しく不足しておりEDINETから取得価値が高い。
- D: 意味解釈または正規化が不安定。raw保存を優先しcanonical化を保留。

## 実装順序

初期候補:

1. 従業員数
2. 平均給与
3. 平均年齢
4. 平均勤続年数
5. 研究開発費
6. 設備投資額
7. 減価償却費

十分なcoverageとvalidation確認後:

- 詳細BS/PL/CF
- 大株主
- セグメント
- 政策保有株
- 大量保有報告
- 開示テキスト

取得難易度、意味の安定性、研究価値を評価し、段階的に実装する。
